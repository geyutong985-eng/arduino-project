# 当前预实验计算方法说明

本文说明当前 `tools/compute_dtw_thresholds.ps1` 的计算逻辑。当前方案不是旧的“三个姿态文件”方案，而是：

```text
每位参与者一个 session.txt
两个动作 trial：HALF_RAISED、PICKING
只使用 TRIAL_ACCEPT 的 trial
用 DTW 计算个人动作模板和阈值
```

## 1. 输入文件

每位参与者一个文件夹，例如：

```text
calibration/raw/participant_001/session.txt
```

`session.txt` 中可以包含完整串口输出，不需要人工剪切每个 trial。脚本会自动识别：

```text
TRIAL_START,HALF_RAISED,1
DATA,...
TRIAL_END,HALF_RAISED,1
TRIAL_ACCEPT,HALF_RAISED,1
```

以及：

```text
TRIAL_REJECT,PICKING,2
```

被 `TRIAL_REJECT` 标记的 trial 不参与计算。

## 2. 采集阶段

预实验程序会输出这些阶段：

```text
NEUTRAL_START / NEUTRAL_END
FLEX_STRAIGHT_START / FLEX_STRAIGHT_END
FLEX_BENT_START / FLEX_BENT_END
TRIAL_START / TRIAL_END
TRIAL_ACCEPT / TRIAL_REJECT
```

其中 neutral pose 用于 Madgwick 相对角度基准，Flex straight / bent 用于 Flex angle 计算。

## 3. DATA 字段

每条数据格式为：

```text
DATA,timeMs,phase,trialId,action,
imu1Ax,imu1Ay,imu1Az,imu1Gx,imu1Gy,imu1Gz,
imu2Ax,imu2Ay,imu2Az,imu2Gx,imu2Gy,imu2Gz,
upperAngle,forearmAngle,
flexRaw,flexAngle,
pressureRaw,pressurePressed
```

其中：

- `imu1` 是上臂 IMU
- `imu2` 是前臂 IMU
- `upperAngle` 是上臂相对 neutral pose 的节段相对姿态角
- `forearmAngle` 是前臂相对 neutral pose 的节段相对姿态角
- `flexAngle` 来自 Flex 伸直/弯曲基线映射
- `pressureRaw` 会记录，但当前第一版不直接放入 DTW 主距离

## 4. DTW 使用的特征

当前 DTW 特征为 9 维：

```text
[
  imu1Ax, imu1Ay, imu1Az,
  imu2Ax, imu2Ay, imu2Az,
  upperAngle / 90,
  forearmAngle / 90,
  flexAngle / 90
]
```

陀螺仪 `gyro` 数据会被预实验程序输出，主要用于 Madgwick filter 计算角度；当前 DTW 脚本不直接把 gyro 放入距离计算。

## 5. Trial 序列

每个合格 trial 会被转换成一段时间序列：

```text
T = [frame1, frame2, ..., frameN]
```

每个 `frame` 是上面的 9 维特征。

脚本在生成 ESP32 头文件前会先降采样 trial。默认每段最多保留 25 帧，后续 DTW 阈值、模板和 ESP32 端实时比较都使用同一套降采样尺度。

## 6. 单帧距离

两个 frame 的局部距离使用平方距离：

```text
d(a, b) = sum((a[j] - b[j])^2)
```

## 7. DTW 距离

两段 trial：

```text
A = [a1, a2, ..., an]
B = [b1, b2, ..., bm]
```

DTW 动态规划：

```text
DTW[i][j] = d(ai, bj) + min(
  DTW[i-1][j],
  DTW[i][j-1],
  DTW[i-1][j-1]
)
```

最终距离会除以 path length：

```text
dtwDistance = DTW[n][m] / pathLength
```

这样可以减少长动作天然距离更大的问题。

## 8. 动作阈值

每个动作保留多个 accepted trial 作为模板库。脚本用“留一法”估计内部距离：

```text
nearestDistance(trial_i) = min(DTW(trial_i, other accepted trials))
```

然后生成阈值：

```text
dtwThreshold = max(nearestDistance) * multiplier
```

当前默认：

```text
accepted trial 数量 <= 3 时，multiplier = 2.0
accepted trial 数量 > 3 时，multiplier = 1.5
```

## 9. 输出文件

运行：

```powershell
.\tools\compute_dtw_thresholds.ps1 -SessionFile .\calibration\raw\participant_001\session.txt
```

输出：

```text
calibration/dtw_threshold_report.csv
calibration/dtw_templates.json
main/DTWCalibrationData.h
```

`dtw_threshold_report.csv` 记录每个动作的 accepted trial 数、最近邻 DTW 距离和阈值。

`dtw_templates.json` 保存每个动作的模板序列和 DTW 阈值，后续可供电脑端/VR 端分析使用。

`main/DTWCalibrationData.h` 是正式实验程序直接读取的 C/C++ 头文件，里面包含：

- `DTW_FEATURE_COUNT`
- `DTW_MAX_TEMPLATE_FRAMES`
- `DTW_ACTION_HALF_RAISED` / `DTW_ACTION_PICKING`
- 降采样后的模板数组
- 每个动作对应的 DTW threshold

默认每个模板最多保留 25 帧，每个动作最多保留 4 个模板。可以通过参数调整：

```powershell
.\tools\compute_dtw_thresholds.ps1 -SessionFile .\calibration\raw\participant_001\session.txt -MaxTemplateFrames 25 -MaxTemplatesPerAction 4
```

正式实验上传 `main/main.ino` 前，先跑一次脚本即可；头文件不需要手动编辑。

## 10. 和 Word 文档的对应关系

当前实现对应 Word 文档中的核心要求：

- 每位参与者单独校准
- 每个动作采集 3 到 6 次合格 trial
- 使用个人正确 trial 作为参考模板
- 用 DTW 最近模板规则进行动作相似性判断
- 记录上臂角度、前臂角度和 Flex
- 保留 min/max + margin、`mean ± 2SD` 作为后续报告和工程调参依据

需要谨慎表述的部分：

- 当前角度是“节段相对姿态角”，不是精确医学关节角
- 当前不直接测量躯干补偿
- 当前不直接测量手部空间位置
- min/max + margin 是工程化容差，不是临床阈值
