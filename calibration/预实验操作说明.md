# 预实验操作说明

本文说明如何使用 `pretest_calibration/pretest_calibration.ino` 采集预实验数据。

## 1. 文件分工

正式实验程序：

```text
main/main.ino
```

预实验程序：

```text
pretest_calibration/pretest_calibration.ino
```

预实验数据保存位置：

```text
calibration/raw/participant_001/session.txt
```

每个参与者一个文件夹，一个 `session.txt` 保存该参与者完整预实验串口输出。

## 2. 本轮采集内容

先采基础校准：

- neutral pose
- Flex 伸直基线
- Flex 弯曲基线

再采两个动作 trial：

| 命令 | 动作 | 内容 |
|---|---|---|
| `1` | `HALF_RAISED` | 从起始位置到 Half-raised |
| `2` | `PICKING` | 从 Half-raised 到 Picking |

每个动作建议至少保留 3 到 6 次 accepted trial。

## 3. 串口命令

| 命令  | 功能               |
| --- | ---------------- |
| `n` | 记录 neutral pose  |
| `f` | 记录 Flex 伸直基线     |
| `b` | 记录 Flex 弯曲基线     |
| `1` | 选择 `HALF_RAISED` |
| `2` | 选择 `PICKING`     |
| `s` | 开始当前动作 trial     |
| `e` | 结束当前动作 trial     |
| `a` | 标记刚结束的 trial 合格  |
| `r` | 标记刚结束的 trial 不合格 |
| `h` | 打印帮助             |

## 4. 推荐流程

1. 上传：

```text
pretest_calibration/pretest_calibration.ino
```

2. 打开串口监视器，波特率：

```text
115200
```

3. 参与者保持自然放松姿态，输入：

```text
n
```

4. 参与者保持肘部伸直，输入：

```text
f
```

5. 参与者做目标弯曲姿态，输入：

```text
b
```

6. 选择 Half-raised：

```text
1
```

每次 trial：

```text
s
让参与者从起始位置做到 Half-raised
e
合格输入 a，不合格输入 r
```

重复直到有 3 到 6 次 accepted trial。

7. 选择 Picking：

```text
2
```

每次 trial：

```text
s
让参与者从 Half-raised 做到 Picking
e
合格输入 a，不合格输入 r
```

重复直到有 3 到 6 次 accepted trial。

8. 预实验结束后，把完整串口输出一次性复制到：

```text
calibration/raw/participant_001/session.txt
```

不需要每次 trial 单独复制。脚本会自动忽略 rejected trial。

## 5. 输出格式

Marker 示例：

```text
NEUTRAL_START
NEUTRAL_END
FLEX_STRAIGHT_START
FLEX_STRAIGHT_END
FLEX_BENT_START
FLEX_BENT_END
ACTION_SET,HALF_RAISED
TRIAL_START,HALF_RAISED,1
TRIAL_END,HALF_RAISED,1
TRIAL_ACCEPT,HALF_RAISED,1
```

DATA 字段：

```text
DATA,timeMs,phase,trialId,action,
imu1Ax,imu1Ay,imu1Az,imu1Gx,imu1Gy,imu1Gz,
imu2Ax,imu2Ay,imu2Az,imu2Gx,imu2Gy,imu2Gz,
upperAngle,forearmAngle,
flexRaw,flexAngle,
pressureRaw,pressurePressed
```

其中 `upperAngle` 和 `forearmAngle` 是基于 Madgwick filter 和 neutral pose 计算的节段相对姿态角，不使用 yaw 作为核心判定。

## 6. 计算

运行：

```powershell
.\tools\compute_dtw_thresholds.ps1 -SessionFile .\calibration\raw\participant_001\session.txt
```

输出：

```text
calibration/dtw_threshold_report.csv
calibration/dtw_templates.json
main/DTWCalibrationData.h
```

`main/DTWCalibrationData.h` 会被正式实验程序自动 include。预实验数据算完后，不要手动改这个文件，重新上传 `main/main.ino` 就会使用这位参与者的 DTW 模板。

正式实验程序里新增了两个相关串口命令：

| 命令 | 功能 |
|---|---|
| `m` | 重新记录正式实验当前 neutral pose |
| `q` | 开关 DTW 匹配结果串口输出 |

正式实验开始前，让参与者回到和预实验一致的 neutral pose，可以输入一次 `m`。程序启动时也会自动记录一次 neutral。
